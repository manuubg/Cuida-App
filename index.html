Projeto de TCC

Cuida+: um sistema integrado para apoio ao cuidado de idosos

O projeto reúne um aplicativo para o cuidador, um dispositivo com telas TFT e um backend em tempo real para organizar medicamentos, registrar eventos e comunicar situações de emergência.

Ver a estrutura do projeto

O Projeto

Sobre o TCC

A ideia central do Cuida+ é aproximar o cuidador da rotina do idoso por meio de um sistema conectado. O cuidador acompanha informações pelo aplicativo, enquanto o dispositivo físico apresenta lembretes e oferece uma forma simples de interação para o idoso.

Em vez de concentrar todo o cuidado em uma única tela, a solução distribui as responsabilidades entre o frontend, o backend e o dispositivo embarcado. Assim, cada parte do sistema tem uma função definida e os dados podem ser atualizados em tempo real.

Desenvolvimento

Como o sistema foi construído

01

Frontend e aplicativo

O aplicativo foi desenvolvido com React Native e executado com Expo Go. Ele concentra o login, o cadastro do perfil, o gerenciamento de medicamentos, o histórico e a edição dos dados do cuidador e do idoso.

React Native · Expo Go
02

Backend e dados

O Firebase Realtime Database funciona como backend da aplicação. Ele armazena perfil, medicamentos, eventos do histórico e informações de SOS, permitindo a sincronização entre o aplicativo e o dispositivo.

Firebase Realtime Database
03

Dispositivo e interface física

A parte eletrônica utiliza Arduino para controlar o dispositivo, os botões de interação e as telas TFT. O hardware foi pensado para apresentar informações objetivas e ser acessível ao idoso.

Arduino · TFT · Botões físicos

Recursos

Funcionalidades

01

Gestão de medicamentos

Cadastro de nome, dose, quantidade, horário, observações e foto do medicamento para apoiar o controle da rotina.

02

Alerta de SOS

O acionamento de emergência é enviado ao sistema e pode gerar um registro no histórico e uma notificação para o cuidador.

03

Histórico de eventos

Registro das confirmações de medicamentos e das ocorrências importantes, incluindo a possibilidade de informar o motivo de um SOS.

04

Perfil do cuidado

Dados do cuidador e do idoso ficam organizados em um perfil que pode ser consultado e atualizado pelo aplicativo.

05

Sincronização em tempo real

As alterações no Firebase são acompanhadas pelo aplicativo para manter as informações do cuidado atualizadas.

06

Interface acessível

O app e o dispositivo utilizam informações diretas, botões destacados e uma organização voltada para o uso cotidiano.

Dispositivo físico

Telas TFT e fluxo de interação

As telas TFT fazem parte da interface do dispositivo utilizado pelo idoso. Elas exibem as informações essenciais sem exigir que o usuário navegue pelo aplicativo do cuidador.

Tela 01LembreteExibe o medicamento e o horário programado.
Tela 02ConfirmaçãoPermite indicar que a medicação foi tomada.
Tela 03EmergênciaApresenta a ação de SOS e envia o evento ao sistema.
